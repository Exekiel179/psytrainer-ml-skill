# Agent Setup

Before installing the runtime, remind the user of the two options: load a local
PsyTrainer wheel if they have one, or proceed without a wheel and use this
Skill’s Pipeline scripts (local code). Wheel is optional; never require
`--legacy` / `--wheel` CLI flags. See [SKILL.md](../SKILL.md).

Download `psytrainer-ml-skill.zip` from the repository's latest GitHub Release.
Extract its complete `psytrainer-ml/` folder into the requested host directory:

| Host | User directory | Invocation |
|---|---|---|
| Claude Code | `~/.claude/skills/psytrainer-ml` | `/psytrainer-ml` |
| Codex | `~/.agents/skills/psytrainer-ml` | `$psytrainer-ml` |
| PsyClaw | `~/.psyclaw/skills/psytrainer-ml` | `/skill:psytrainer-ml` |

For project-only Claude Code/Codex installation, use the project's `.claude/skills/`
or `.agents/skills/`. The final path must be `psytrainer-ml/SKILL.md`, without
another nested folder. Claude Code cannot discover a Skill in a Codex directory;
if absent after placement, open a new session and check disabled/same-name skills.

From the Skill root, run `python3 scripts/install_runtime.py` on macOS/Linux;
on Windows run `powershell -ExecutionPolicy Bypass -File scripts\install_runtime.ps1`.
Setup requires installed CPython 3.12-3.14; `--python PATH` selects one explicitly.
It creates `.venv` and records its interpreter in `runtime.json`. `ready` means
the environment exists, not that optional packages are installed.

## Pipeline (default, no PsyTrainer wheel)

If the user does not load a wheel, use this path: `install_runtime.py` creates
`.venv` / `runtime.json`, and agents run `scripts/pipeline_train.py` (the Skill’s
own implementation—no vendor wheel). Offline dependency directories use
`--wheelhouse PATH` (prebuilt packages only), which is separate from PsyTrainer.

```bash
python3 scripts/install_runtime.py
"$PY" scripts/pipeline_train.py train ...
```

## Optional PsyTrainer wheel (historical INI only)

Do not pass CLI flags for wheel/legacy. Configure one optional source, then rerun
the same setup command; when a wheel is found, setup also writes `.venv-legacy`
and `runtime-legacy.json`. When none is found, setup stays Pipeline-only.

| Option | How |
|---|---|
| Environment | `export PSYTRAINER_WHEEL=/path/to/PsyTrainer-0.2.0-cp314-none-any.whl` |
| Config file | Copy `config/optional-wheel.path.example` to `config/optional-wheel.path` and put one path/glob on a non-comment line |
| Auto-discover | Place a single `PsyTrainer-*.whl` under the Skill root or `vendor/` |

```bash
export PSYTRAINER_WHEEL=/path/to/PsyTrainer-0.2.0-cp314-none-any.whl
python3 scripts/install_runtime.py
# use runtime-legacy.json -> python for historical INI jobs
```

Missing or ambiguous wheels are skipped. See [migration.md](migration.md).
To list historical INI engine capabilities after that environment exists:
`PSYTRAINER_LEGACY=1 "$PY_LEGACY" scripts/ml.py capabilities`.

Task commands check their dependencies each time, without network access when
requirements are satisfied. Do not preinstall everything or run sample training.
Reports are generated by scripts without model calls. For normal tasks read
[SKILL.md](../SKILL.md); the full README is only needed for unusual setup issues.

## Download Recovery

On failure, show the missing packages and exact command printed by the CLI.
The user may run it manually or have their coding agent run it. Choose a reachable
source, then rerun the original task. Example from the Skill root:

```bash
python3 scripts/install_runtime.py --packages xgboost --index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

Use the corresponding packages from the error. Windows PowerShell uses
`-Packages xgboost -IndexUrl URL`. A local dependency directory uses
`--wheelhouse PATH` / `-Wheelhouse PATH` instead of the index. Saved source settings
apply to later task installs. Installed uv can be selected with `--installer uv`.
Defaults: 20-second socket timeout, 2 retries, 600-second installation budget;
`--timeout`, `--retries`, `--max-seconds` adjust these. Retry reuses installed
packages and completed caches. Missing native libraries need system repair
(e.g. LightGBM on macOS: `brew install libomp`). Never report a failed task as ready.
